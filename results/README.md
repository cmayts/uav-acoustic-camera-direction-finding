# Analysis results

The analyzer writes each run to a subdirectory named after the input recording. Generated artifacts can include:

- Snapshot and per-second CSV summaries
- Direction-of-arrival plots and heatmaps
- Spectrogram and average-spectrum plots
- Detection and confidence timelines
- Harmonic summaries
- Presentation notes

The images in `examples/` are synthetic illustrations. They demonstrate the expected presentation style and are not UAV measurements or validation evidence.

Generated run outputs are excluded from version control by default. Keep only intentionally selected, anonymized examples in `results/examples/`.
